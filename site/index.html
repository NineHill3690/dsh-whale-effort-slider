鲸鱼推理滑条 v1.3.0 两个版本 怎么装 注意

推理档位，拖一下就换了

DSH 输入框里原来那个只显示模型名的按钮，换成一条带鲸鱼的滑条。 拖到哪一档就是哪一档，海流的密度和速度跟着变，推到底会喷气。 两个下载包只差面板材质：一个实色卡片，一个半透明玻璃，动画一模一样。

两个版本，只差一行

打包脚本把 client.js 里的一行常量翻过来，其余文件逐字节相同。 所以两个包不会各走各的：修 bug 同时生效，外观各取所需。

它到底做了什么

都是实装的，不是动效占位。

档位

档位由模型自己给

插件不写死刻度。模型上报几档就画几个刻度点，DeepSeek 常见是 Off / Low / High / Max 四档。

拖拽

跟手，不跳格

拖动期间滑条用连续值，指针事件按帧合并；松手才吸附到最近的刻度，吸附值不会反写回滑条。

海流

档位越高，水流越急

二十二道水流细丝按档位决定数量和速度；到 Max 会换成 Ultra 材质，多一层极光和水泡。

喷气

推到顶会喷一下

第一次到达最高档时，鲸鱼头顶喷出一束水，十一片水滴散开。只在真正到顶时触发，来回蹭不会重复喷。

模型

模型列表两级下钻

点模型名进列表，按厂商分组，支持子序列搜索和方向键 / Home / End / Enter，Esc 一层层往回退。

主题

深浅色都跟着走

面板底色、描边、投影、文字墨色、滑条水色、鲸鱼填充全部按主题取值，切换主题不用重开面板。

该装哪个

两个包同名同席位，只能装一个。想换版本就先卸掉原来的。

安装

不用命令行，也不用构建。解压后是个完整插件目录。

  1. 完全退出 DSH Desktop托盘里也要退干净，否则插件目录被占用。
  2. 把解压出来的文件夹放到一个不会被清理的地方别放下载目录，系统清缓存时会连插件一起删。 例如 D:\plugins\dsh-whale-effort-slider
  3. 打开 DSH Desktop → 设置 → 插件 → 添加插件选上面那个文件夹，然后完全退出再重开 DSH。

得说清楚的几件事

  • 它顶掉的是官方模型选择器。插件占用输入框的模型席位并优先显示，所以装上之后输入框里看到的就是这条滑条，不是官方那个按钮。
  • 和官方选择器别同时开。两个都声明同一个席位时，先声明的会被后者报错顶掉，历史上有过一次装完模型选择器整个消失的事故。
  • 两个版本不能同时装。包名相同、席位相同，装第二个只会让第一个失效。
  • 失败不连坐。模型目录拉不下来时只在面板里显示一行错误，输入框和聊天不受影响，也不会留下残留钩子。
  • 档位名是模型给的。不同厂商上报的 id 不一样（mid、xhigh、ultra 等），插件只做归类和排序，不凭空造档。
  • 只改了输入框那一个位置。不注入 host hook，不改会话数据，卸载即消失。
